# REPOSICIÓN — v1.0.0

App de compras en Once para **Madro**, **Ligux** y **Elugas**. Dos usuarios: **Tomás** y **Martín**. Contraseña: un espacio + Confirmar.

## Instalar en el celular (Android + Chrome)

1. Dejá esta PC prendida con el servidor corriendo (luz verde en la app).
2. Abrí el link HTTPS en Chrome.
3. Menú ⋮ → **Agregar a la pantalla principal**.
4. El ícono es fondo negro con **11** blanco.

## Arrancar en esta PC

```bat
iniciar.bat
```

O:

```bat
npm run build
npm start
```

Y en otra ventana el túnel Cloudflare (lo abre `iniciar.bat`).

## Reportar

- **Martín:** aviso a Tomás (push + cartel en la app + toast en Windows).
- **Tomás:** queda en `inbox/` para aplicarlo.

Luz: verde online · amarillo trabajando · rojo trabado · apagada = el programa no corre.
